# Level 1 Task 25 Capstone 3

## The Task Manager

*  Created a task manager to manage tasks assigned to each member of the team.

*  Code written in Python 3
*  Notepad will be required for the generated text files.

<!-- Horizontal Rule -->
---
___

*  Useful Project features:

   1) Users/ Admin will be allowed to add new tasks and edit old tasks.
   2) User/ Admin will be allowed to view all tasks.
   3) Users/ Admin will be allowed to view their tasks only.
   4) User/ Admin will be able to change their passwords. 
   5) Admin will be able to register new users.
   6) View user and task statistics.
   7) Generate reports.
